# Image Generator Using OpenAI

This project uses OpenAI's API to generate images based on text prompts. The application is divided into two parts: a frontend running on `http://localhost:3000/` and a backend running on `http://localhost:8001/`.

## Project Structure

- **Frontend**: A user interface where users can enter a text prompt to generate an image. Built with HTML, CSS, and JavaScript.
- **Backend**: A Node.js server that interacts with the OpenAI API to generate images based on the user's input.

## Installation

### Prerequisites

- Node.js (v14 or higher)
- OpenAI API key (sign up at [OpenAI](https://platform.openai.com/) to get your API key)
